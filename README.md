# JARAK KESEKOLAH

JARAK KESEKOLAH adalah aplikasi berbasis web/mobile yang membantu pengguna mengetahui jarak dan perkiraan waktu perjalanan dari rumah menuju sekolah.

## Teknologi

Aplikasi ini dikembangkan menggunakan:

- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap
- OSRM
- Nominatim
- GPS Geolocation API
- Google Maps
